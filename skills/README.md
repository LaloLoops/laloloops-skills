# Skill Categories

This directory holds copied or rewritten skills organized by category.

## Categories

### `content/`

Skills for turning development sessions, transcripts, or project activity into
journals, summaries, and reusable content ideas.

Included skills:

- `journal-session-history` - summarizes development work from local agent
  session transcripts.
- `journal-session-current` - turns the current conversation or provided notes
  into a journal summary and content ideas.

### `git/`

Skills for PR descriptions, review management, CI follow-up, and merge loops.

Included skills:

- `pr-manage`

### `project-management/`

Skills for planning new work, reading project state, ranking next steps, and
maintaining progress trackers.

Included skills:

- `agent-comm`
- `feature-planning-scaffold`
- `live-implementation-notes`
- `project-next-steps`

### `media/`

Skills for generated images, transparent PNG/WebP assets, cutouts, and related
media asset workflows.

Included skills:

- `transparent-image-alpha`
